The model and the data

We modeled single-family sale prices in Chicago from 2023-2025 using house characteristics and spatial features. The training file contains 23,200 sales with observed prices; the test file contains 5,789 homes with prices withheld. We kept the outcome in dollars, compared 16 models using 10-fold cross-validation, and examined residual patterns and valuation ratios by neighborhood income.

Assessment errors matter because they can place unequal burdens on households. The 2017 Chicago Tribune investigation, “The Tax Divide,” motivates our comparison of relative valuation errors across income groups.

check_na <- function(formula, df) {
  vars <- all.vars(formula[[3]])
  bad <- vars[sapply(vars, function(v) any(is.na(df[[v]])))]
  if (length(bad) > 0) {
    stop("These variables have NAs: ", paste(bad, collapse = ", "),
         ". Fill them or choose another variable (Rule 1).")
  }
}

# Same folds, with prediction safeguards learned from each training fold.
cv_cache <- new.env()
guard_features <- function(newdata, training, formula) {
  vars <- all.vars(formula[[3]])
  for (v in vars) if (is.numeric(training[[v]])) {
    bounds <- range(training[[v]],na.rm=TRUE)
    newdata[[v]] <- pmax(bounds[1],pmin(bounds[2],newdata[[v]]))
  }
  newdata
}
cv_fit <- function(formula, data) {
  key <- paste(deparse(formula),collapse="")
  if (!exists(key,cv_cache,inherits=FALSE)) {
    d <- st_drop_geometry(data)
    check_na(formula,d)
    set.seed(5080)
    folds <- caret::createFolds(d$sale_price,k=10,returnTrain=TRUE)
    pred <- rep(NA_real_,nrow(d)); rmse <- numeric(10)
    for (i in seq_along(folds)) {
      tr <- folds[[i]]; val <- setdiff(seq_len(nrow(d)),tr)
      model <- lm(formula,data=d[tr,])
      heldout <- guard_features(d[val,],d[tr,],formula)
      pred[val] <- pmax(0,predict(model,newdata=heldout))
      rmse[i] <- sqrt(mean((d$sale_price[val]-pred[val])^2))
    }
    assign(key,list(results=data.frame(RMSE=mean(rmse)),pred=data.frame(rowIndex=seq_len(nrow(d)),pred=pred)),cv_cache)
  }
  get(key,cv_cache)
}
cv_rmse <- function(formula,data) cv_fit(formula,data)$results$RMSE
cv_pred <- function(formula,data) cv_fit(formula,data)$pred$pred

# Chicago Data Portal (Socrata) -> sf. `where` is a SoQL filter.
socrata_get <- function(dataset, where, select = NULL, limit = 200000) {
  where <- str_squish(where)
  q <- paste0("$where=", URLencode(where, reserved = TRUE), "&$limit=", limit)
  if (!is.null(select)) q <- paste0(q, "&$select=", URLencode(str_squish(select), reserved = TRUE))
  url <- paste0("https://data.cityofchicago.org/resource/", dataset, ".geojson?", q)
  tmp <- tempfile(fileext = ".geojson")
  resp <- tryCatch(download.file(url, tmp, quiet = TRUE), error = function(e) e)
  if (inherits(resp, "error")) stop("Portal request failed. Open this URL in a browser to see why:\n", url)
  st_read(tmp, quiet = TRUE)
}

Most variables are categorical (house features). The continuous variables are sale price, building square footage, building age, and lot size in acres. Our response value is highly skewed and have extreme outliers, which can is evident from the range and standard deviations. The objective of this study is to fix the overestimated price predictions for lower value homes. This overevaluation may be a result of low and high outliers reducing the efficacy of model predictions. The actual cleaning rule below uses 1.5-IQR bounds on log price, once, on training rows only.

IQR for outliers

The IQR was used to identify outliers rather than standard deviation because sales price generally uses the median and the high skewness of the data requires a stricter condition. In total, 939 of 23200 training sales were removed. No test rows were removed. This distribution-based rule does not establish that excluded sales were non-market. It can worsen prediction for low- and high-value homes.

First, the dependent variable is extremely skewed. There are very few houses that sell for many times the price of a median house and very few that are sold at extremely low prices. We excluded the log-price tails for this model, but unusual prices are not necessarily non-market transactions, so this choice limits generalization. Furthermore, the continuous variables that were highly skewed were logged to better fulfill linear regression assumptions.

Second, pairwise plots alone cannot rule out multicollinearity, and some categorical features may be redundant. Interaction effects should be tested out. There are also a lot of variables to add, which means a stepwise regression would be beneficial for variable selection.

Lastly, house sales price are clustered depending on location. The Northeast end seems to have a higher sale prices. Adding a fixed effect variable will be useful for accounting for this.

moran <- function(formula, df, response, k = 5) {
  rmse <- cv_rmse(formula, df)
  pred <- cv_pred(formula, df)
  resid_cv <- df[[response]] - pred
  
  coords <- st_coordinates(df)
  
  w_knn <- nb2listw(knn2nb(knearneigh(st_coordinates(df), k = k)), style = "W")
  
  moran_res <- moran.test(resid_cv , w_knn)
  moran_i <- moran_res$estimate[["Moran I statistic"]]
  moran_p <- moran_res$p.value
  
  tibble(
    moran_i = moran_i,
    moran_p = moran_p
  )
}

The model log records each trial in order. In every validation fold, numeric predictors are limited to that fold’s training range and predictions are floored at zero. The same rule is used for final test predictions to prevent extreme extrapolation, especially from very small lots. This safeguard does not guarantee accurate prices for unusual homes. The largest one-step improvement came from m13: community. Baseline CV RMSE was $219,610; the final selected formula has CV RMSE $135,451. Community effects allow prices to differ across Chicago. Transit and affordable-housing features should be judged by the log; their coefficients are associations, not causal effects.

Stepwise selection used all retained training rows before CV. Its CV score is conditional on that selected formula and may be optimistic. Nested selection is needed to validate the full selection procedure. Repeated sales can also occur across random CV folds, unlike the instructor’s house-level test split.

This connects to The Tax Divide: acceptable overall dollar error can hide unequal relative burdens on cheaper homes. Our IQR cleaning removes both price tails, which can reduce representation of very low-value homes and hide some overvaluation. These results describe retained training sales, not every household. Our model keeps sale price in dollars and combines house features with location. Age class C starts at 50 years in our code, and class A is below 20. The class C coefficient compares those age groups while holding other model terms constant.

We read the bus-distance coefficient in two ways. Its fitted coefficient is 53778.14 dollars per mile. With the size-by-community interaction, a 10% increase in building size changes the prediction by log(1.10) times that community’s size slope.

We would not hand this model to the Assessor for direct use yet. The final CV score estimates error on retained training sales, while the instructor’s test prices are still withheld. check_na <- function(formula, df) {
  vars <- all.vars(formula[[3]])
  bad <- vars[sapply(vars, function(v) any(is.na(df[[v]])))]
  if (length(bad) > 0) {
    stop("These variables have NAs: ", paste(bad, collapse = ", "),
         ". Fill them or choose another variable (Rule 1).")
  }
}

# Same folds, with prediction safeguards learned from each training fold.
cv_cache <- new.env()
guard_features <- function(newdata, training, formula) {
  vars <- all.vars(formula[[3]])
  for (v in vars) if (is.numeric(training[[v]])) {
    bounds <- range(training[[v]],na.rm=TRUE)
    newdata[[v]] <- pmax(bounds[1],pmin(bounds[2],newdata[[v]]))
  }
  newdata
}
cv_fit <- function(formula, data) {
  key <- paste(deparse(formula),collapse="")
  if (!exists(key,cv_cache,inherits=FALSE)) {
    d <- st_drop_geometry(data)
    check_na(formula,d)
    set.seed(5080)
    folds <- caret::createFolds(d$sale_price,k=10,returnTrain=TRUE)
    pred <- rep(NA_real_,nrow(d)); rmse <- numeric(10)
    for (i in seq_along(folds)) {
      tr <- folds[[i]]; val <- setdiff(seq_len(nrow(d)),tr)
      model <- lm(formula,data=d[tr,])
      heldout <- guard_features(d[val,],d[tr,],formula)
      pred[val] <- pmax(0,predict(model,newdata=heldout))
      rmse[i] <- sqrt(mean((d$sale_price[val]-pred[val])^2))
    }
    assign(key,list(results=data.frame(RMSE=mean(rmse)),pred=data.frame(rowIndex=seq_len(nrow(d)),pred=pred)),cv_cache)
  }
  get(key,cv_cache)
}
cv_rmse <- function(formula,data) cv_fit(formula,data)$results$RMSE
cv_pred <- function(formula,data) cv_fit(formula,data)$pred$pred

moran <- function(formula, df, response, k = 5) {
  rmse <- cv_rmse(formula, df)
  pred <- cv_pred(formula, df)
  resid_cv <- df[[response]] - pred
  
  coords <- st_coordinates(df)
  
  w_knn <- nb2listw(knn2nb(knearneigh(st_coordinates(df), k = k)), style = "W")
  
  moran_res <- moran.test(resid_cv , w_knn)
  moran_i <- moran_res$estimate[["Moran I statistic"]]
  moran_p <- moran_res$p.value
  
  tibble(
    moran_i = moran_i,
    moran_p = moran_p
  )
}

The model log records each trial in order. In every validation fold, numeric predictors are limited to that fold's training range and predictions are floored at zero. The same rule is used for final test predictions to prevent extreme extrapolation, especially from very small lots. This safeguard does not guarantee accurate prices for unusual homes. The largest one-step improvement came from `r model_log$model[which.max(c(0,-diff(model_log$cv_rmse)))]`: `r model_log$added[which.max(c(0,-diff(model_log$cv_rmse)))]`. Baseline CV RMSE was $`r format(round(model_log$cv_rmse[1]),big.mark=",")`; the final selected formula has CV RMSE $`r format(round(cv_rmse(f_stepwise,clean_train)),big.mark=",")`. Community effects allow prices to differ across Chicago. Transit and affordable-housing features should be judged by the log; their coefficients are associations, not causal effects.

Stepwise selection used all retained training rows before CV. Its CV score is conditional on that selected formula and may be optimistic. Nested selection is needed to validate the full selection procedure. Repeated sales can also occur across random CV folds, unlike the instructor's house-level test split.

## Reflection


Our model keeps sale price in dollars and combines house features with location. Age class C starts at 50 years in our code, and class A is below 20. The class C coefficient compares those age groups while holding other model terms constant. 

We read the bus-distance coefficient in two ways. Its fitted coefficient is `r round(coef(m_final)["dist_bus_mi"],2)` dollars per mile. For the prediction, moving from 0.1 to 0.2 miles from a bus stop changes the fitted value by $`r round(0.1*coef(m_final)["dist_bus_mi"],2)`, holding the other terms constant. This is a conditional association. It does not show that moving a stop would cause that price change. With the size-by-community interaction, a 10% increase in building size changes the prediction by log(1.10) times that community's size slope.

We would not hand this model to the Assessor for direct use yet. The final CV score estimates error on retained training sales, while the instructor's test prices are still withheld. Selection before CV and repeated sales across folds can make that estimate optimistic. The income ratio table matters because households can face different relative errors even when overall RMSE improves.

Our cleaning rule also needs caution: it identifies unusual prices, not verified non-market sales. It removes some low-value homes that matter most for the fairness question. Crime counts use only events before each sale, but early 2023 has less observation history. The supplied amenity files lack historical snapshot dates. We would first verify those dates, review excluded sales, use property-grouped validation, and test the entire selection process inside the folds. More complex models could be compared later, but improved accuracy must be demonstrated. Interpretability is useful; it does not make an estimate fair or ready to set tax bills.
